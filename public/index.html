أَوْرَادُ الْعَنِيْضَمِيَّةِ

Aurod An-Anidhomiyyah

Aplikasi untuk membaca wirid dan dzikir harian

Cara Install di HP:

  1. Buka website ini di browser HP (Chrome/Safari)
  2. Tekan tombol Menu (⋮) di browser
  3. Pilih "Tambahkan ke Layar Utama" atau "Add to Home Screen"
  4. Aplikasi akan muncul di layar HP seperti app biasa
